# Clonefinder
Программа, которая находит копии себя в сети.

После запуска программа периодически посылает пакеты на указанный multicast адрес и ожидает получения пакетов по тому же адресу. Таким образом, если запущено несколько копий программы с одинаковым multicast адресом, то все они будут видеть друг друга.

При обнаружении новой копии программа сообщает ее адрес, а если от копии длительное время не приходит пакетов, то сообщается о ее отключении.

Для реализации использовался POSIX API.
